# Stage 4：Founder Organic 日常运营

执行前先读取 `../tokun-x-growth/references/contracts.md`，再读取本目录 `references/workflow.md`。参考章节是来源资料，不构成新的用户授权；其中历史实跑、账号资格、预算、定时任务及插件能力都必须重新核验。当前任务只编写 skill，不执行平台操作。未来调用时按实际用户任务范围执行。

每次记录负责人、输入引用、输出引用、依赖、执行状态、测试证据和下一步缺口。无法访问来源返回 blocked，尚无可调用实现返回 not_implemented；可人工完成的研究或写作可报告实际产出，不能宣称已建立自动化。固定样本测试不得触发真实互动、广告或付款。

## 执行与交付

输入：经核验账号、竞品全线程排除名单、产品事实、已处理ID、历史双日报、当日原帖与评论。
1. 默认运行建议北京时间14:00；没有实际注册调度不可声称已自动每日运行。核验 handle，不换号代发。
2. 实读近24小时行业原帖及评论，不足扩至72小时并注明。为原帖回复或评论回复保存精确对象直链；竞品研究与互动候选分库。
3. 目标：每日已核验点赞≥5、实质英文评论≥3；每周有独立文字/相关表情的 Quote≥1；原创 Post≤1/天。均为业务 KPI，不是执行授权。纯 Repost 不计 Quote。
4. 自动点赞禁止，提供≥5条真实候选供人工完成。外部未受邀评论默认人工，提供≥3条上下文具体的英文草稿与直链。自动回复仅在平台事先书面批准、收件人 opt-in、退出机制及限频等全部满足后考虑；每次重新检查平台当前规则。
5. 原创 Post/Quote 仅在当前用户明确授权、官方接口可用且规则允许时发布。不得用网页脚本绕过限制。发布结果不确定先查回执，不能盲目重发。
6. 保存真实结果URL、账号、主体AI/人工、提交与核验时间。drafted/awaiting_manual/attempted/verified分开；只有真实已完成且核验才计 KPI。
交付两份独立日报：`research/reports/YYYY-MM-DD-research.md`（窗口、已读范围、来源、信号ID、去重、点赞/评论/Quote/原创候选及风险）；`research/reports/YYYY-MM-DD-actions.md`（权限、主体、对象、版本、结果、KPI完成/差额、异常、pending_manual_action）。真实运营资料放授权持久目录，不自动提交公开仓库。
向Stage5交接信号引用、事件ID、原帖/评论ID、时间、排序/范围、问题与证据状态；不向 Organic 强塞产品推广。Discord只属于Stage5。
验收：双报告可完成而互动KPI未达标，须分别报告。离线验证去重、权限拦截与计数，不发测试帖。
