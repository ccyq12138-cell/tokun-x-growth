2.3 每轮研究的操作步骤
             1. 维护名单。 直接竞品、相邻基础设施和跨品类参考分组；核验官方账号、创始人与
                产品关系。沿用现有排除名单，但新增账号须附官网/主页证据。Fabrice Mayrand
                和 CheaperInference 只进入竞品研究模块。
             2. 采集窗口。 日常研究优先近 7 天，专题回溯另标历史窗口；打开原帖及实际可见评
                论，记录原帖链接、采集时间、可见指标、评论排序和已读样本数。对公开广告身
                份未核验的帖子标记“付费状态未知”。
             3. 按同一张证据卡拆解。 每条记录受众、痛点、开头钩子、主张、证据形式、图片/视
                频结构、CTA、作者回复、用户问题、产品链接与限制。截图/原图只证明其画面内
                容，不能证明投放状态或转化。
             4. 验证产品比较。 价格采用同一模型版本、同一输入/输出单价口径与采集日期；实际
                成本另考虑缓存、重试、成功率和工作负载。兼容性按具体协议及模型测试，不把
                “统一 API”扩大成全部 SDK 功能。Tokun 的公开产品事实以最新官网/docs 和产品
                负责人确认版本为准。
             5. 提取原创机会。 每条机会写成“用户问题 → Tokun 可提供的证据 → 内容形式 → 适
                用账号 → CTA → 未核验处”。首批优先四题：同模型价格如何公平比较；账单如何
                展示实际服务商；首次 API 调用最少需要哪些步骤；为什么成功任务成本比单次
                token 指标更有用。若缺产品实测，先做方法论/清单，不发性能结论。
             6. 更新矩阵与去重。 按品牌、帖子 ID、campaign 事件和语义主题去重；官方帖与
                founder 转述可分别存素材，但同一发布不计两次市场事件。每日简报的价格、稳
                定性、接入、支持问题只当研究线索，需独立核实后进入对外话术。
